# إضافة وظائف

قواعد التحقق المشتركة في `packages/shared/src`، وقواعد حفظ المنتجات في `server/src/catalog-service.ts`، ومسارات المحتوى في `routes-content.ts`، والواجهة الإدارية في `admin/src/Content.tsx`. يقرأ المتجر البيانات عبر `src/data/CatalogContext.tsx`.

لإضافة حقل: حدّث مخطط Prisma وZod والتحويل إلى DTO وقاعدة الحفظ، ثم الواجهة. أضف migration جديدة دون تعديل migration سبق تطبيقها. الأسعار تُرسل نصوصًا عشرية من الإدارة وتُحفظ Decimal، والتواريخ UTC. استخدم JSON للنصوص المرنة وجداول علاقات للقيم المستخدمة في البحث والفلاتر. إضافة تعريف مواصفة وحده لا يسمح بمفتاح يخالف مخطط المواصفات المشترك؛ وسّع المخطط والواجهة معه.

لإضافة صلاحية: عدّل تعريفات الأدوار المشتركة وطبّق `permission` على مسار الخادم قبل إظهار الزر. حماية React وحدها لا تكفي. احفظ تعديل البيانات وإدخال سجل العملية داخل معاملة واحدة، ولا تضف مسارًا لتعديل أو حذف السجل. لا تسجل كلمات المرور أو tokens أو مفاتيح TOTP.

لإضافة module: افصل منطق الأعمال عن Fastify وReact، وأضف مساراته داخل نطاق الإدارة المحمي. لا تضف بيانات داخلية إلى `/api/catalog`. استخدم مراجعة `updatedAt` لمنع الكتابة فوق تعديل مستخدم آخر، واختبر فعلًا صلاحية المنع وليس مجرد إخفاء زر.

أوامر الفحص: `npm run build:all` و`npm run typecheck` و`npm run lint` و`npm test`. لاختبار قاعدة فعلية، عيّن `TEST_DATABASE_URL` لقاعدة محلية بحساب قادر على إنشاء قاعدة اختبار، ثم `npm run test:integration`. يرفض الاختبار خادمًا بعيدًا. اختبارات الواجهة: `npm run test:ui`؛ ثبّت Chromium أو عيّن `PLAYWRIGHT_CHANNEL=chrome`.

قبل التحديث: نسخة SQL والأسرار، بناء جديد، migrations الجديدة، حماية التدقيق، تشغيل جديد، health، تحقق الصور والمحتوى والدخول. لا تحذف قاعدة أو مجلد صور لإصلاح بناء.
