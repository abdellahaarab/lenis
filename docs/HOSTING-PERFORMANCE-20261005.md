## التغييرات

- ملفات JavaScript وCSS التي يضيف Vite بصمة إلى اسمها: `public, max-age=31536000, immutable` بدل مدة صفر للمتجر و`no-store` لملفات الإدارة الثابتة.
- ملفات HTML للمتجر: إعادة تحقق عند الاستخدام لتلقي أسماء ملفات الإصدار الجديد.
- صفحات الإدارة والحسابات والسلة: تبقى `no-store`. لم يتغير تخزين الكتالوج القصير ولا صلاحيات المستخدمين.
- الملفات الثابتة غير المبصومة: ساعة واحدة مع إعادة التحقق؛ لا تطبق مدة السنة على الصور أو الملفات ذات الاسم الثابت.
- التحويل من `/` إلى `/ar` أصبح على الخادم قبل عرض تطبيق React، لتجنب عرض التذييل قبل الصفحة الرئيسية أثناء تحويل اللغة.
