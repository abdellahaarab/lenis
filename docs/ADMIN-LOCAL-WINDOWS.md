# تشغيل الإدارة محليًا على Windows

هذا المسار يستخدم PostgreSQL المثبت مباشرةً على Windows عند تعذّر تشغيل Docker. يتطلب Node 22.13 أو أحدث وPostgreSQL 16 أو 18. قاعدة التطوير مستقلة عن قواعد PostgreSQL الأخرى، وتستمع إلى `127.0.0.1:55432` فقط.

من CMD، شغّل السطر التالي واترك النافذة مفتوحة:

```cmd
cd /d "C:\Users\User\Downloads\alarbi\lenis" && npm run dev:local
```

الأمر يجهّز قاعدة التطوير، ويولّد Prisma، ويطبّق الترحيلات، ثم يشغّل API على 3001 ولوحة الإدارة على 5174. يستخدم أسرار البنية التحتية الموجودة في `.env` ويتغيّر فيها `DATABASE_URL` فقط؛ تبقى إعدادات Docker مستقلة لأنها تضبط عنوانها داخل Compose. لا يُنشئ حسابات موظفين أو بيانات تجارية.

في نافذة CMD ثانية، أنشئ حساب المالك ببياناتك الفعلية:

```cmd
cd /d "C:\Users\User\Downloads\alarbi\lenis" && npm run seed:owner
```

أدخل الاسم والبريد، ثم كلمة مرور مخفية. الضغط على Enter عند طلب كلمة المرور يولّد كلمة عشوائية تُعرض مرة واحدة. افتح <http://localhost:5174/admin/>. يتطلب أول دخول تغيير كلمة المرور.

بيانات القاعدة تُحفظ في `E:\Aljeel-dev\lenis-admin\data` عندما يتوفر E، وإلا داخل `.temp/local-postgres` في المشروع. يمكنك تحديد مسار مختلف عبر `ALJEEL_PG_DATA_ROOT`، أو مجلد برامج PostgreSQL عبر `LOCAL_PG_BIN`. استخدم القيم نفسها في كل تشغيل. يسجّل السكربت مسار المشروع ويرفض التعامل مع مجلد تابع لمشروع آخر.

إيقاف نافذة التشغيل بـ Ctrl+C يوقف التطبيقات ويحفظ بيانات القاعدة. لإيقاف أي عملية قاعدة متبقية بأمان، استخدم `npm run db:local:stop`. إعادة تشغيل `npm run dev:local` تستخدم البيانات الموجودة. لا تبدأ Compose على 3001 و5174 أثناء تشغيل هذا المسار. المشغّل محلي للتطوير؛ إصلاح مخزن مكونات Windows وتفعيل VirtualMachinePlatform مطلوبان لتشغيل Docker لاحقًا.
