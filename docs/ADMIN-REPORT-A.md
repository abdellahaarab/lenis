# تقرير المرحلة A — 2026-10-02

تم تنفيذ المرحلة A فقط على الفرع `feature/admin-system` داخل المستودع الفعلي `lenis/`. وحدات المحتوى والعملاء والمبيعات والاشتراكات والزيارات مُعرّفة في قاعدة البيانات، وتُنفّذ واجهاتها وعملياتها في مراحل B–D. لم يُربط المتجر بالـAPI؛ ذلك للمرحلة E.

## ما بُني

- مساحات عمل npm والحزمة المشتركة. مخططات الكتالوج الأصلية نُقلت دون إعادة تعريف المنتج، ويعيد المسار القديم تصديرها. لم تُعدّل أقسام المتجر أو حركاته أو CSS ضمن عمل الإدارة.
- 24 نموذج Prisma وجميع العلاقات والفهارس الأساسية، وترحيل PostgreSQL مع قيود الأسعار والكميات والضمان والهاتف والتوافق والبيانات المنشورة. سجل التدقيق محمي من التعديل والحذف بواسطة trigger.
- Fastify، التحقق من البيئة، سجلات منظمة تقلل البيانات الشخصية، Helmet، CORS محدد، CSRF حتى على تسجيل الدخول، حدود حجم الطلبات ومعدلات الطلب، فحص الصحة وOpenAPI في التطوير فقط.
- جلسات قاعدة بيانات مخزنة كهاش، انتهاء خمول ومدة مطلقة، تدوير الجلسة عند الدخول وتغيير كلمة المرور، إلغاء الجلسات، argon2id، قفل حساب مؤقت، TOTP مشفر ومنع إعادة استخدام الرمز، وإلزام تغيير كلمة المرور المؤقتة.
- مصفوفة صلاحيات الأدوار الخمسة على الخادم، إدارة الموظفين للمالك، التعطيل وإعادة التفعيل وإعادة تعيين كلمة المرور وTOTP، وحماية آخر مالك نشط. كل تعديل إداري يُسجل في معاملة واحدة مع التغيير.
- واجهة `/admin/` عربية/إنجليزية، RTL/LTR، مظهران، قائمة هاتفية، تسجيل دخول، موظفون، حساب وأمان وجلسات، سجل نشاط، صفحات 403/404، حوارات تأكيد وإشعارات. لوحة البداية فارغة بوضوح دون إحصاءات مختلقة.
- بحث الموظفين مع تأخير الإدخال وتطبيع الحروف العربية، وتقسيم صفحات على الخادم. التنقل مرتبط بالصلاحيات.
- `.env.example` وتهيئة أسرار عشوائية، وأمر تفاعلي لإنشاء المالك. لم يُنشأ حساب حقيقي أو عملاء أو بيانات مبيعات افتراضية.
- إعداد Docker للتطوير واختبارات PostgreSQL معزولة وتوثيق التشغيل وسجل التغييرات وقائمة معلومات المالك.

## التشغيل

من `lenis/`:

```sh
npm install
npm run env:init
npm run db:generate
docker compose -f docker-compose.dev.yml up --build
docker compose -f docker-compose.dev.yml exec -it api npm run seed:owner
```

افتح `http://localhost:5174/admin/`. أدخل الاسم والبريد الحقيقيين في CLI؛ أدخل كلمة مرور مخفية أو اضغط Enter لتوليد كلمة عشوائية تظهر مرة واحدة. غيّرها عند أول دخول. لا تُحفظ الأسرار في Git.

للتشغيل المحلي دون حاويات التطبيق، شغّل خدمة PostgreSQL فقط، ثم `npm run db:migrate` و`npm run seed:owner`، وشغّل `npm run dev:server` و`npm run dev:admin` في طرفيتين. التفاصيل في `admin-foundation.md`.

## حدود وتسليم

- إعداد A للتطوير، وليس نشر HTTPS إنتاجيًا. Secure معطل صراحة على HTTP المحلي ومطلوب في إعداد الإنتاج. إلزام 2FA للمالك والتدقيق الأمني النهائي والنسخ الاحتياطية واستعادة قاعدة البيانات للمرحلة F.
- فحص كلمات المرور يحظر أنماطًا شائعة محليًا، وليس فحصًا شاملًا لكل كلمات المرور المسربة؛ ذلك موثق للمراجعة الأمنية النهائية.
- تحذيرات حجم حزم Vite ومواضع تعليقات PURE في Zod موجودة؛ البناء ينجح. يعرض المتجر تحذيرًا بمنتجات demo وصور غير مرخصة وحقول تواصل فارغة، وهي بياناته الموجودة وليست بيانات أضافها نظام الإدارة.
- كانت هناك تعديلات وملفات غير متتبعة للمتجر قبل العمل، وظهرت تعديلات محلية أخرى أثناءه. لم تُلغَ أو تُضمّن تغييرات التصميم والحركات في commits الإدارة. مخططات/اعتماديات البناء الحالية استُخدمت كما وجدناها.
- لا تتضمن A عمليات إدخال البيانات التجارية أو رفع الوسائط أو إرسال الرسائل أو التحليلات؛ الواجهة تذكر مرحلة توفرها بوضوح.

الخطوة التالية: تشغيل قاعدة PostgreSQL 16، إنشاء المالك عبر CLI، ومراجعة الواجهة؛ ثم طلب **المرحلة B** لبناء تحرير المنتجات والمحتوى والوسائط والنشر والاستيراد.

## متابعة تشغيل Windows — 2026-10-02

تعذّر تشغيل Docker بسبب فشل تفعيل VirtualMachinePlatform بخطأ Windows 14098. جرى تجاوز خطأ ملفات اتصال Docker المؤقتة بحفظ مجلداتها بأسماء احتياطية؛ تهيئة المحرك نفسه بقيت غير ناجحة.

أُضيف مسار تطوير محلي مستقل: `npm run dev:local`. استُخدم PostgreSQL **18.3** المثبت، مع قاعدة تطوير جديدة في `E:\Aljeel-dev\lenis-admin\data` على `127.0.0.1:55432`؛ لا تُستخدم قاعدة النظام القائمة. تغيّر عنوان القاعدة في `.env` المحلي فقط، وبقيت أسراره ومفاتيح الجلسات والتشفير محفوظة وخارج Git.

التحقق الفعلي: تهيئة القاعدة وتطبيق الترحيل الأولي نجحا؛ إعادة التشغيل استخدمت القاعدة نفسها وأظهرت عدم وجود ترحيلات معلقة؛ `/api/health` عبر الواجهة أعاد `200` وحالة `ok`، وصفحة الإدارة وCSRF أعادتا `200`. جميع المنافذ 3001 و5174 و55432 تستمع على loopback فقط. رفض المشغّل نسخة تشغيل ثانية عند إشغال المنفذ. فحص lint نجح. عدد المستخدمين الحقيقيين **صفر**؛ لم يُنشأ حساب أو تُدخل بيانات أعمال. إنشاء المالك عبر CLI ببياناته الحقيقية يظل مطلوبًا. دليل التشغيل في `ADMIN-LOCAL-WINDOWS.md`.
